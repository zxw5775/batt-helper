# Batt Helper 产品需求文档（PRD）

## 1. 文档信息

- 产品名称：Batt Helper
- 产品形态：macOS 桌面应用 + 状态栏应用
- 技术架构：Electron
- 核心引擎：基于 `batt`
- App 作者：`zxw | gpt5.4`
- Core powered by：`batt`
- batt 作者：`charlie0129`
- batt 仓库：[https://github.com/charlie0129/batt](https://github.com/charlie0129/batt)

## 2. 产品背景

`batt` 已提供 Apple Silicon MacBook 的电池充电控制、充电上限限制、校准、供电控制、睡眠保护等核心能力，但其原生 GUI 更偏极客工具形态，不适合普通用户进行完整的可视化管理。

Batt Helper 的目标是基于 `batt` 构建一套更现代、更友好、更适合分发的 macOS 应用体验，包括：

- 美观的主界面仪表盘
- 简洁统一的状态栏入口
- 充电策略管理
- 电池健康信息展示
- 自动校准与调度配置
- 明暗主题、多语言、开机自启动、关于页等完整桌面应用能力

## 3. 产品目标

### 3.1 核心目标

- 将 `batt` 的 CLI / daemon 能力完整 GUI 化
- 提供专业但易用的电池管理体验
- 支持状态栏快速操作与主窗口详细管理双模式
- 建立品牌化视觉体系与可分发产品形态

### 3.2 业务价值

- 降低命令行使用门槛
- 提升工具的可视化与可理解性
- 提升长期插电办公用户的电池保养体验
- 为后续版本扩展统计、策略推荐、更新系统打下基础

## 4. 用户画像

### 4.1 核心用户

- Apple Silicon MacBook 用户
- 长期插电办公用户
- 对电池寿命、健康度、充电策略敏感的开发者与办公用户
- 希望通过 GUI 管理 `batt` 的非终端用户

### 4.2 用户需求

- 方便地设置充电上限与下限差值
- 在状态栏快速查看当前电池状态
- 理解当前电池健康状况
- 在需要时进行自动校准
- 通过主题和语言切换获得更好的桌面体验

## 5. 产品定位

Batt Helper 是一款面向 macOS 的桌面电池管理应用，基于 `batt` 核心能力，提供可视化、品牌化、状态栏友好的电池控制与健康管理体验。

## 6. 范围定义

### 6.1 P0 范围（首版必须）

- 首次引导与 daemon 检测
- batt daemon 安装引导
- 仪表盘首页
- 当前电量 / 充电状态 / 供电状态展示
- 充电上限设置
- lower limit delta 设置
- 禁用充电限制
- 状态栏单一图标 + 菜单入口
- 开机自启动
- 明暗主题切换
- 中英文多语言框架
- 关于页与版本信息

### 6.2 P1 范围（首个增强版本）

- 自动校准 GUI
- 校准调度 GUI
- 高级功能管理（睡眠保护、MagSafe 等）
- 健康趋势图
- 通知与日志导出

### 6.3 非目标

- 不重写底层充电控制逻辑
- 不绕过系统/硬件限制
- 不做用户账户系统
- 不做云同步
- 不做跨平台版本

## 8. 核心功能需求

### 8.1 首次启动引导

#### 目标

帮助用户完成环境检测、daemon 安装和初始配置。

#### 流程

1. 欢迎页
2. 兼容性检查
3. daemon 检测
4. daemon 安装引导
5. 默认充电策略设置
6. 开机启动设置
7. 完成

#### 验收要求

- 能清晰提示是否已安装 daemon
- 能提示管理员权限需求
- 能在失败时提供可恢复路径

### 8.2 仪表盘 Dashboard

#### 目标

一屏展示用户最关心的电池核心状态。

#### 显示内容

- 当前电量百分比
- 当前状态：Charging / Discharging / Full / Not Charging
- 是否接电源
- 是否允许充电
- 当前上限 / 下限
- 预计到达上限时间
- 电池健康度
- 循环次数
- AC Power / Battery Power / System Power
- 校准状态
- 调度状态

#### 交互要求

- 状态 5 秒内自动刷新
- 设置项操作后立即刷新
- 状态不可用时显示降级提示

### 8.3 Charging 页

#### 目标

提供完整的充电策略与供电控制能力。

#### 功能

- 设置上限百分比
- 设置 lower limit delta
- 快捷预设：60 / 70 / 80 / 90 / 100
- 禁用限制
- 适配器启停
- Force Discharge

#### 交互要求

- 高风险操作需二次确认
- 成功 / 失败给出明确反馈
- 显示当前策略是否已生效

### 8.4 Health 页

#### 目标

帮助用户理解电池当前健康与使用状态。

#### 显示内容

- 健康度百分比
- 循环次数
- 满充容量（若底层可得）
- 电压
- 当前充电速率
- 供电功率信息
- 健康建议文案

### 8.5 Calibration 页

#### 目标

将 `batt` 的自动校准与调度能力可视化。

#### 功能

- 查看校准当前阶段
- Start / Pause / Resume / Cancel
- 配置放电阈值
- 配置满电停留时长
- 查看下次调度时间
- 管理调度开关

#### 风险提示

- 合盖可能导致睡眠
- 校准期间建议接通电源
- 若未接电源需提示用户

### 8.6 Settings 页

#### 功能分组

- General
  - Launch at login
  - Start in tray mode
  - Minimize to tray
  - 通知开关
- Appearance
  - Follow system
  - Light
  - Dark
- Language
  - 简体中文
  - English
  - 繁體中文（预留）
- Advanced
  - batt daemon 状态
  - 版本检测
  - 日志导出
  - socket/config 高级路径
- About
  - App 版本
  - 作者
  - Core powered by batt
  - batt 作者与仓库地址

### 8.7 状态栏 Tray

#### 设计原则

- 只使用一个稳定 Logo 图标
- 不使用状态切换图标
- 状态变化通过菜单文案与主界面展示

#### 菜单内容

- 当前电量
- 当前充电状态
- 当前限制值
- Open Dashboard
- Quick Preset
- Open Settings
- Quit

## 9. 视觉与品牌要求

### 9.1 品牌方向

- 主题色：紫色系
- 风格：简洁、友好、轻品牌化、接近 macOS 桌面应用审美
- Logo：电池主体 + 轻量笑脸

### 9.2 主题要求

- 支持浅色 / 深色 / 跟随系统
- 图表与卡片在深色模式下保持良好对比度

## 10. 多语言要求

- P0 支持：`zh-CN`、`en-US`
- 预留：`zh-TW`
- 所有页面文案、按钮、错误提示、Tooltip 均需国际化

## 11. 权限与兼容性要求

- 需要清晰区分“App 自启动”和“batt daemon 安装”
- daemon 安装需要管理员权限
- 对不支持机型/系统需要展示兼容性提示
- 对 daemon 未运行、版本不匹配、权限不足要有错误引导

## 12. 成功指标

- 用户无需终端即可完成充电管理
- 状态栏可作为应用常驻入口
- 用户能在 30 秒内理解当前电池状态
- 用户能在 3 次点击内完成常见充电策略切换
